# Conglomerate Buyer Collection Ships

This folder contains collection-ship artwork for the Stage 8 **Conglomerate Buyers Service**.

## Preferred naming

Use sequential WEBP filenames:

- `buyer-ship-0001.webp`
- `buyer-ship-0002.webp`
- ...
- `buyer-ship-1000.webp`

Buyer Ship N belongs to Buyer N in the canonical content directory.

## Generation reference

Use:

`docs/Progression Stages/Stage 8/BuyerAndShipImageDirectory.html`

The SHIPS tab provides the stable ship name, assigned buyer/company, one of the 30 approved ship classes, cargo capacity and the image-generation description for every vessel.

## Visual direction

- landscape / wide composition;
- entire vessel visible in a clear three-quarter exterior view;
- grounded, high-detail industrial science-fiction style consistent with MineIT;
- ship-class silhouette should remain recognisable across different company liveries;
- practical cargo doors, holds, loading equipment and propulsion appropriate to the class;
- buyer/company-specific commercial livery;
- no combat emphasis;
- readable hull text is not required.

The artwork pool may be built gradually. Missing artwork must never break the eventual buyer-contract or collection-event UI.
